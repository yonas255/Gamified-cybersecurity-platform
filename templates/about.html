Project Overview

This platform is a gamified cybersecurity training environment designed to help students learn common web vulnerabilities in a safe and controlled environment.

Users practice exploiting vulnerabilities such as SQL Injection, Cross-Site Scripting (XSS), Cross-Site Request Forgery (CSRF), Insecure Direct Object Reference (IDOR), and Broken Access Control.

Project Info
  • Developer: Yonas Haftom
  • Technologies: Flask, Python, SQLite
  • Frontend: Bootstrap
  • Purpose: Educational cybersecurity training
⚡ Vulnerability Labs

Practice exploiting common web security vulnerabilities using realistic but safe simulations.

🛡 Secure Coding

Every vulnerable lab includes a secure version that demonstrates how developers fix the vulnerability.

🏆 Gamified Learning

Solve Capture-the-Flag challenges, track progress, and compete on the leaderboard.
