SQL Injection

SQL Injection occurs when user input is directly inserted into a database query. Attackers can manipulate the query to bypass authentication or retrieve sensitive data.

In these labs you will exploit vulnerable SQL queries and then learn how secure coding practices such as parameterized queries prevent the attack.

Start SQL Injection Labs

Cross-Site Scripting (XSS)

Cross-Site Scripting allows attackers to inject malicious JavaScript into web pages viewed by other users.

You will practice both reflected and stored XSS attacks and learn how secure output encoding protects web applications from these threats.

Start XSS Labs

Access Control Vulnerabilities

Access control vulnerabilities occur when applications fail to properly restrict what authenticated users are allowed to do.

In these labs you will explore IDOR and Broken Access Control vulnerabilities by manipulating URLs and accessing restricted resources.

Start Access Control Labs
