Why this worked
{% if mode == "vuln" %}

In vulnerable mode, the application reflects your input directly into the page without escaping. The browser treats it as real HTML/JavaScript and executes it.

Example payload:

<script>alert('XSS')</script>

This is called Reflected XSS because the payload is reflected immediately in the response.

{% else %}

In secure mode, the application escapes your input. Characters like < and > are treated as text instead of HTML.

So scripts are shown on screen but not executed — preventing XSS.

{% endif %}
How it’s fixed
  • Escape/encode output before rendering
  • Validate and sanitize input where appropriate
  • Use security headers like Content Security Policy (CSP)
