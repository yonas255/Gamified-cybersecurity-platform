# Gamified-cybersecurity-platform

A web-based Capture-the-Flag (CTF) platform designed for cybersecurity education at NCI.
This repository will contain the source code for the platform as development progresses.

## Feature
- User Registration and login
- Vulnerable vs Secure cybersecurity labs
- SQL Injection, XSS, CSRF, IDOR, AND Broken Acess Control simmulation
- progress tracking and leaderboard
- Role-based admin access
- Flag submission and scoring system

## Technologies
- Python
- Flask
- SQLite
- Bootstrap
- HTML, CSS, JavaScript
- PyTest

## Running the Project

### 1. Install dependencies

`` bash
pip install -r requirements.txt

### 2. Create admin account

Windows CMD:
set BOOTSTRAP_ADMIN_EMAIL=admin@example.com
set BOOTSTRAP_ADMIN_PASSWORD=StrongPassword123
python app.py

### 3. Open in browser

http://127.0.0.1:5000

### 4. Testing 
run unit tests using

``bash
python -m pytest -v
